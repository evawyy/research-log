# Concurrent-SCIP 与算法组合

## 核心问题

在固定线程数、时间和内存下，怎样组织多个不同配置的 SCIP worker，使求解比单个 default 配置更稳定高效？

## 当前结果

- Mixed time-gap loss：测试集相对 default 改善约 5.63%。
- 48 个测试实例中严格改善 21 个。
- PAR-2：相对改善约 2%，成功求解数增加 1。

## 当前判断

配置之间存在互补性，但收益可能集中于少数实例；平均 loss 之外还需要逐实例贡献、性能剖面和成功求解数。
